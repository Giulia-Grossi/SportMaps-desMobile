# Sport-Maps

### Programação Para Dispositivos Móveis II - Bruno Zolotareff Dos Santos

### Projeto desenvolvido por: 
### Giulia Gomes Grossi
### João Victor de Sousa

#### A proposta deste site é ajudar os usuários a encontrar espaços para praticar esportes diversos como skate, patins, bicicleta e etc, visto que além de espaços oficiais há também muitas áreas abertas que são propícias para as práticas mas que não são muito conhecidas ou divulgadas. 
#### Além de trazer estas informações, nosso site recomendará produtos ideais para cada espaço, garantindo que o usuário tem tudo que precisa para tirar proveito do espaço, como equipamento adequado, kits de segurança, e merchandising (talvez com parceria de marcas).

## Para iniciar, utilize os comandos npm install e npm run dev dentro da pasta sport-maps
